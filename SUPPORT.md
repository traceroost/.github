# Getting help

- **Documentation:** [docs.traceroost.com](https://docs.traceroost.com) covers installing,
  connecting each agent, the dashboard, TraceRoost Cloud, and the CLI and configuration reference.
- **Bugs and feature requests:** open an issue in
  [traceroost/core](https://github.com/traceroost/core/issues/new/choose). Include the TraceRoost
  version (bottom-left of the Traces tab, or `traceroost --version`), how you run it, and the agent
  you were using.
- **Anything else:** email [support@traceroost.com](mailto:support@traceroost.com).
- **Security issues:** report them privately as described in [SECURITY.md](SECURITY.md).
